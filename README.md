# doesman1227.github.io

個人サイト m-note（https://m-note.uk/）のハブ（トップページ）。GitHub Pages のユーザーサイトで、`CNAME` により独自ドメインで配信しています。

各ノートは独立したリポジトリで、同じドメインのサブパス（例：`https://m-note.uk/quantum/`）で公開されます。

トップの一覧は4つのグループで整理しています。

- 世界のしくみ（WORLD）— 量子力学、時間
- 社会のしくみ（SOCIETY）— 経営戦略、AIエージェント経営、宗教(仏教の思想史・原始仏教・神道と神社)、歴史(年表と古典)
- 人間のしくみ（HUMAN）— 脳のしくみ、発達障害、健康と習慣
- 意識のしくみ（MIND）— マインドフルネス、認知行動療法、感情、哲学、人生観、セカンドブレイン

このほかに「日々のつぶやき」（`/musings/`）があります。
