# doesman1227.github.io

個人サイト m-note（https://m-note.uk/）のハブ（トップページ）。GitHub Pages のユーザーサイトで、`CNAME` により独自ドメインで配信しています。

各ノートは独立したリポジトリで、同じドメインのサブパス（例：`https://m-note.uk/quantum/`）で公開されます。

トップの一覧は5つのグループで整理しています。

- 世界のしくみ（WORLD）— 物理学(力学・電磁気学・熱力学・相対性理論・時間・量子力学・素粒子と宇宙)、数学、生物学
- 社会のしくみ（SOCIETY）— 経営戦略、AI(AIエージェント経営)、宗教(十の宗教のノートと比較)、歴史(年表と古典)
- 人間のしくみ（HUMAN）— 脳、発達障害
- 意識のしくみ（MIND）— マインドフルネス、認知行動療法、感情、考え方、哲学
- 自分のしくみ（SELF）— 生き方、働き方、お金、楽しみ方、健康と習慣（自分で選んだ生き方と、それを回すしくみ）

このほかに、一覧の先頭に「m-note について」（`/about/`、このサイトの成り立ちと仕組み）と「日々のつぶやき」（`/musings/`）があります。
